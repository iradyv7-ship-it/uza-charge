# UZA Charge — demo guide (28 October 2026)

How to run the whole platform on one laptop and walk a room through it in about 20 minutes. Everything below was
run end to end on 27 October 2026 against the simulated charger; the checks are listed at the end.

## 1. Start it (one command)

Pull each repo's branch first (section 5), then, in `uza-charge-api`:

```bash
bash scripts/demo.sh
```

About two minutes later it prints:

| App | Address | Sign in with |
|---|---|---|
| Driver app | http://localhost:5173/c/HEI-001-1 (scan path, gun 1) · http://localhost:5173/find (map) | nothing for scan-and-pay; any phone number for history and bookings |
| Owner portal | http://localhost:5174 | **0788000001** (owner admin) · 0788000003 (second owner) · 0788000002 (host, read-only) |
| Operator (attendant) | http://localhost:5175 | signed in as the attendant at Kigali Heights |
| NOC console | http://localhost:5176 | **0788000009** (NOC) · 0788000010 (network admin) |

Sign-in codes are shown on screen in this mode. Choose any PIN that is not `123456`-like. Payments are simulated: a
MoMo push confirms after a few seconds. Data lives in memory and resets when you press Ctrl-C, so every demo starts
clean. The API listens on :3017 because the VPN's routing service holds :3000 on this laptop; do not stop it.

If a step stalls: the logs are in `uza-charge-api/.demo/`. Nothing in this mode reaches a real charger, a real phone
or real money.

## 2. The story to tell (in this order)

1. **Driver: scan, pay, charge, receipt** (driver app, `/c/HEI-001-1`). The price before paying (energy + service,
   and when it changes), MoMo, "checking with the charger" (accepted is not charging), the live screen with **energy,
   cost, power, battery, voltage and current**, stop, and the receipt with the tariff breakdown and **battery start →
   end**. Point out that nothing is ever shown as 0 when the charger has not reported it.
2. **Driver: map and booking** (`/find`). Sites on the map, a gun booked for a time slot, the queue position stated
   honestly.
3. **Owner: add a site and a charger with no engineer** (owner portal → Sites → New site → Add charger). The
   one-time password, the `wss://` address, and the printable QR label per gun.
4. **Owner: test mode** (charger page → **Test mode**). Open a window "before go-live" for 2 hours, start a **free
   test charge** on a gun, watch it appear once the charger reports it, stop it, end the window. Then show that the
   test charge is on the charges list at zero and out of revenue, and that a driver scanning that gun meanwhile is
   told the charger is being tested and is not charged.
5. **Owner: prices** (Prices). A simple price per kWh, optional time of day, every change a new version published
   with confirmation, a version scheduled for later.
6. **Owner: money and reports** (Home, Money, Payouts, Reports, Analysis, P&L, Compliance, RURA reports). The
   numbers an owner and an investor ask for, every one labelled Measured, Calculated or Entered.
7. **Owner: map visibility** (Sites → edit → "Show this site on the drivers' map"). Untick and the site leaves the
   driver map at once.
8. **Attendant** (operator app). Start a charge for a cash customer, sell and top up a charging card, record a
   complaint.
9. **NOC** (NOC console). The estate, one charger's maintenance console (configuration, raw OCPP log, reset,
   diagnostics), **Test mode** after a repair, load management, complaints, the regulator view.

## 3. What to say when asked "what is not real yet"

Say it plainly; it is all recorded in the build reports.

- No real charger has connected yet; everything runs against the simulator (§1.2). The Wicen unit on staging is next.
- MTN MoMo and Airtel need provider credentials (`AWAITING CREDENTIALS`); SMS needs a provider.
- Sign-in is pilot-only; identity moves to UZA ID before general release (decided 25 Oct).
- Kinyarwanda is written for every screen but not yet reviewed by a native speaker.
- Store-published apps (Play Store / App Store) are Phase 4; the driver app installs from the browser today.

## 4. Checks run on 27 October 2026

- Unit and screen tests: API 1,394 (incl. PostgreSQL), gateway 428, owner portal 225, NOC 199, driver app 197.
- `scripts/e2e.sh`: the driver journey and the admin journey over real HTTP and OCPP, including the new
  commissioning section (refused outside a window, confirmation required, start, live energy, stop, zero-priced
  COMMISSIONING session, close).
- A live smoke run through the apps' own proxies against `scripts/demo.sh`: owner sign-in, test mode open, a
  driver's paid start refused, free test charge started, live volts/amps/start battery shown, stopped, receipt at
  zero with battery start → end, test mode closed, a site hidden from and returned to the map — 12 of 12 passed. It
  found one real bug (the receipt re-priced a test charge from the tariff), fixed before this guide was written.
